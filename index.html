DotNetSolutionKit AboutО шаблоне DocsДокументы SamplesПримеры GitHub

A configurable dotnet new template and lifecycle toolkit for .NET 8 solutions on PostgreSQL or SQL Server. The template generates microservices with CI, deployment and tests, wired together; flags add the rest. The tool dotskit adds services and flags to a solution and upgrades it to a new version, keeping the team's code.

Настраиваемый шаблон dotnet new и инструмент сопровождения решений на .NET 8 с PostgreSQL или SQL Server. Шаблон генерирует связанные между собой микросервисы с CI, деплоем и тестами, остальное включается флагами. Инструмент dotskit добавляет в решение сервисы и флаги и обновляет его до новой версии, сохраняя код команды.

NuGetSawKing.DotNetSolutionKit NuGetSawKing.DotsKit.Tool

dotnet tool install -g SawKing.DotsKit.Tooldotskit new -N MyCompany -P MyProduct -S Orders

Start with the business logic

Начните сразу с бизнес-логики

Layers, errors, auth, logging, tests, Docker and CI are in place after the first command. The solution is an ordinary .NET project the team owns, and its first commit is about the product.

Слои, ошибки, авторизация, логи, тесты, Docker и CI на месте после первой команды. Решение - обычный .NET-проект, которым владеет команда, и её первый коммит уже про продукт.

A new service in one command. dotskit new adds it to the solution with its layers, references, tests and deployment files in place.

Новый сервис одной командой. dotskit new добавляет его в решение сразу со слоями, ссылками, тестами и файлами деплоя.

A solution that keeps up. dotskit adds a service or a flag to an existing solution and upgrades it to a new version of the template, keeping the team's changes.

Решение не отстаёт. dotskit добавляет в готовое решение сервис или флаг и обновляет его до новой версии шаблона, сохраняя правки команды.

The boring part is done. Errors in one format, validation, authorization, health checks, background jobs and one request ID that follows a call through every service and log.

Рутина уже сделана. Ошибки в одном формате, валидация, авторизация, проверки здоровья, фоновые задачи и один ID запроса, который проходит через все сервисы и логи.

Only what you need. A message bus, secrets from Infisical or Vault, object storage, ClickHouse, MongoDB, email, an audit journal, an API gateway - each is a flag, switched on when you need it.

Только то, что нужно. Шина сообщений, секреты из Infisical или Vault, объектное хранилище, ClickHouse, MongoDB, почта, журнал аудита, API-шлюз - каждое включается флагом, когда понадобится.

Deployment included. Docker images, compose or Kubernetes, blue-green deployment and CI on GitHub Actions with tests on a real database.

Деплой в комплекте. Docker-образы, compose или Kubernetes, blue-green деплой и CI на GitHub Actions с тестами на настоящей базе.

See it before you use it. DotNetSolutionKit.Samples holds generated solutions to read through: the full kit, a single service and a gateway with services, generated again from every release, and full-dev, generated from dev, where the next release is built. Each runs its own CI.

Посмотрите до того, как взять. В DotNetSolutionKit.Samples лежат сгенерированные решения: полный комплект, один сервис и шлюз с сервисами, которые пересобираются из каждого релиза, и ветка full-dev, собранная из dev, где готовится следующий релиз. В каждой работает свой CI.

Try it in a minute

Попробуйте за минуту

Install dotskit, the template's tool, from nuget.org:

Установите dotskit, инструмент шаблона, с nuget.org:

dotnet tool install -g SawKing.DotsKit.Tool

The shared libraries, the solution and the first service, in an empty folder:

Общие библиотеки, решение и первый сервис, в пустой папке:

dotskit new -N MyCompany -P MyProduct -S Orders

Every next service, and a flag for a service the solution has:

Каждый следующий сервис и флаг для сервиса, который уже есть:

dotskit new -S Billingdotskit new -S Orders --MongoDB true

A new version of the template, keeping the team's changes:

Новая версия шаблона с сохранением правок команды:

dotskit upgrade

The template alone, by dotnet newТолько шаблон, через dotnet new

Install the template from nuget.org:

Установите шаблон с nuget.org:

dotnet new install SawKing.DotNetSolutionKit

The shared libraries, the solution and the first service:

Общие библиотеки, решение и первый сервис:

dotnet new DotNetSolutionKit -N MyCompany -P MyProduct -S Orders --Solution

Every next service, by the template's short name dotskit:

Каждый следующий сервис, по короткому имени шаблона dotskit:

dotnet new dotskit -N MyCompany -P MyProduct -S Billing

Such a solution is upgraded by dotskit after dotskit init.

Такое решение обновляется через dotskit после dotskit init.

Documentation

Документация

Everything else is in the docs: the architecture, each feature, operations, the decisions behind the parts that depart from common practice, and the roadmap.

Всё остальное - в документации: архитектура, каждая возможность, эксплуатация, решения по тем частям, что отходят от общепринятой практики, и дорожная карта.

A solution of an earlier 2.x version is brought to the current one by dotskit upgrade: git keeps the team's changes where they merge with the template's, and the rest are conflicts to resolve. A solution of v1 is brought to 2.0.0 by hand first: upgrading.

Решение более ранней версии 2.x приводится к текущей через dotskit upgrade: git сохраняет правки команды там, где они сливаются с правками шаблона, остальное - конфликты, которые разрешает команда. Решение v1 сначала руками приводится к 2.0.0: обновление.

What each version brings: version.json and the releases. How versions are made: contributing.
