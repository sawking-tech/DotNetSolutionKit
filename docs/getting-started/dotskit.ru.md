# dotskit

**dotskit** - это две вещи под одним именем: шаблон `dotnet new`, который генерирует решение .NET из
микросервисов, и инструмент командной строки, который его генерирует, дополняет и обновляет. Сгенерированное
решение - обычное решение .NET, принадлежащее команде; шаблон и инструмент - то, с чего оно начинается и чем
держится рядом с шаблоном.

```bash
dotnet tool install -g SawKing.DotsKit.Tool

dotskit new -N MyCompany -P MyProduct -S Orders   # в пустой папке: решение и первый сервис
dotskit new -S Billing --Storage true             # в решении: ещё один сервис
dotskit upgrade                                   # в решении: привести его к версии шаблона, которой соответствует инструмент
```

## С чего войти

- Новое решение: [генерация решения](template.ru.md), дальше инструмент для каждого сервиса после первого.
- Решение, созданное одним шаблоном: `dotskit init` пишет его манифест ([инструмент](tool.ru.md#решение-созданное-без-dotskit)), и дальше работает `dotskit upgrade`.
- Решение, отставшее от текущего выпуска: [обновление решения](upgrading.ru.md).
- Команде, которая взвешивает, браться ли: [что даёт шаблон](what-it-gives.ru.md).
