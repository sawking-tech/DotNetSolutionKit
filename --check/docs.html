The documents of the template

DotNetSolutionKit is a dotnet new template for .NET 8 microservices on PostgreSQL. These are its documents: how to generate a solution, how a service is built, what each switch adds, how it runs in production and why it is made the way it is.

Every document below is a markdown file in the repository, and each link goes to its source.
