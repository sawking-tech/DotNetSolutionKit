  • single - One service with the defaults: PostgreSQL, Hangfire, docker compose files, and CI. filesфайлы, CI reportsотчёты CI
  • gateway - Two services behind a YARP gateway that validates the token and forwards the user. filesфайлы, CI reportsотчёты CI
  • full - Every flag: the bus with an outbox, Infisical, feature flags, the API diff, access rules over a tenant tree, object storage, ClickHouse; two services. filesфайлы, CI reportsотчёты CI
  • full-alt - SQL Server, xUnit, secrets from Vault, Kubernetes manifests and the audit journal, which rides on the bus with an outbox; two services. filesфайлы, CI reportsотчёты CI
  • full-dev - The flags of full and the ones dev adds before a release, generated from the template's dev once a day when it has moved. A red CI here is a break in dev before a release. filesфайлы, CI reportsотчёты CI
