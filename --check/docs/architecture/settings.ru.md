# Настройки

Сервис читает настройки из этих источников, каждый перекрывает предыдущие:

1. `features.json` из Common, с `--FeatureFlags`;
2. `appsettings.json`, затем `appsettings.<Environment>.json`, затем `appsettings.Secrets.json` в `Local`;
3. переменные окружения;
4. хранилище секретов, с `-I` или `--Vault`: общая папка, затем папка сервиса
   ([секреты](../features/secrets.ru.md)).

## Что меняется, пока сервис работает

JSON-файлы перечитываются, когда меняются на диске, а хранилище секретов - каждые `ReloadSeconds`
(по умолчанию 300; 0 - только на старте). Новое значение доходит до того, что читает его при каждом
использовании, и больше ни до чего:

| Меняется без перезапуска | Требует перезапуска |
|---|---|
| [фича-флаги](../features/feature-flags.ru.md), читаются при каждой проверке | строки подключения: база, шина, ClickHouse, MongoDB, объектное хранилище |
| настройки, зарегистрированные через `AddReloadableOptions` и читаемые через `IReloadable<T>` | ключи и издатель JWT, внутренний API-ключ, CORS, источник прав |
| | настройки, зарегистрированные через `AddValidatedOptions`, сервер задач, логирование |

Переменные окружения в работающем процессе не меняются; значение, заданное там, в любом случае требует
перезапуска.

## Настройка, которая меняется на ходу

Настройку, которая читается при каждом использовании, например лимит или список допустимых значений,
регистрируют как перечитываемую:

```csharp
services.AddReloadableOptions<ImportLimits>("ImportLimits");
```

```csharp
public sealed class ImportService(IReloadable<ImportLimits> limits)
{
    public bool Fits(int rows) => rows <= limits.Current.MaxRows;
}
```

На старте она проверяется аннотациями, как любая другая настройка, и сервис с невалидным значением не
стартует. Дальше каждое изменение её секции заново связывается и проверяется: валидное значение заменяет
`Current`, а невалидное пишется в лог предупреждением и отбрасывается. Сервис продолжает работать с
последним валидным значением и не валит запросы из-за опечатки в файле или в хранилище.

`AddValidatedOptions` остаётся для того, что строится из значения один раз: значение читается при первом
использовании и живёт до конца процесса.

## Хранилище секретов, перечитанное

Перечитка читает те же папки, что и старт, в том же порядке. Новые значения заменяют старые и поднимают
токен изменения конфигурации; те же значения ничего не поднимают. Когда хранилище не отвечает, сервис
оставляет свои значения, а в `Secrets:ReloadError` записано, когда и почему последняя перечитка не
удалась. Снимок, если он ведётся, переписывается после каждого удачного чтения.

## Тесты

`Common.Tests` покрывает перечитываемую настройку - валидное значение принято, невалидное отброшено - и
перечитку хранилища: изменённое значение доходит до конфигурации и поднимает токен, те же значения ничего
не поднимают, недоступное хранилище оставляет значения на месте.
